### Sobre mim

</div>

<table align="center">
<tr>
<td>

Sou **Mellina Bizinoto**, tenho 22 anos e estudo **Ciência da Computação no Centro Universitário FEI**. Anteriormente, cursei um ano de Ciência da Computação na FECAP, ampliando minha formação acadêmica na área de tecnologia.

Atuo com desenvolvimento **Front-End e Back-End**, com perfil Full Stack. Também tenho interesse em **dados, sistemas e UI/UX Design**.

Tenho experiência com desenvolvimento de interfaces web, lógica de backend, integração de APIs, bancos de dados SQL e criação de aplicações funcionais.

**Tecnologias:** C#, C++, Assembly, React, Vite, Next.js, Vue.js, SQL, JavaScript, HTML, CSS, JSON, Python, PHP, Unity3D e Tailwind CSS.
